# 使用说明（定制闹钟）

> 本文件与 App 内「设置 → 使用说明」保持一致。

## ① 填 API 与校验

1. 打开「设置 → API 配置」。
2. 默认已选第一个 API 地址，可直接点「测试连通性」。
3. 等待探测完成，看到「校验通过」即可。
4. 若默认地址不通，切换其余预设或填自定义地址再测。

## ② 新建闹钟

1. 回到首页，点右下角「+」新建闹钟。
2. 选好时间、标签与重复（工作日/每天/仅一次）。
3. 设置贪睡、响铃时长、震动与音量渐强。
4. 选铃声来源与歌单 ID 后点「保存」。

## ③ 填歌单 ID

1. 铃声来源选网易云/QQ/酷狗时，需填歌单 ID。
2. 歌单 ID 是 1–20 位纯数字。
3. **获取方法**：在音乐软件的歌单内点「分享」→「复制链接」，链接中 `id=` 后面的数字即为歌单 ID。
4. 点「加载歌单预览」可看曲目数与前 3 首。
5. 保存时会再次校验，空歌单会拒绝保存。

## ④ 在线播放

1. 保存启用后，响铃时 App 在线解析并流式播放第 `nextIndex` 首，**不下载缓存**。
2. 响铃按 Meting 协议分两步：`type=playlist` 拉歌单 → 响铃时 `type=url` 解析真实音频地址。
3. `type=url` 兼容「返回 JSON」与「302 跳转音频 CDN」两种实现。

### 播放失败会怎样

- **网易云 VIP / 版权受限曲目解析不出音频**，响铃时降级为仅震动。
- 无网络或解析失败也会降级为仅震动，请保持响铃时刻网络可用。

### 铃声来源怎么选更稳

- **自定义 → 音频直链**：最稳定，填一个可直接访问的 `.mp3/.m4a/.aac/.ogg/.flac` 地址。
- **自定义 → Meting 模板**：自建 Meting 实例后填入完整模板（含 `server`/`type` 参数），可绕开公共端点。
- **预设端点**：默认 `injahow` 可用；`i-meto` 已失效（401），`meting-ve` 可用但仅供备用。公共端点随时可能变动。

## ⑤ 响铃权限与厂商设置

1. 首次启动按引导授权通知、精确闹钟、全屏通知权限。
2. 建议在设置里开启「忽略电池优化」，避免被省电策略拦截。
3. 小米/华为/OPPO/vivo/三星需在系统管家里允许自启动与后台。
4. 在最近任务里把应用上锁（下拉锁定），避免被划掉。

## ⑥ 常见问题

1. 到点只震动不响：在线解析失败（多为 VIP/版权曲目或无网络），换非付费歌单或改用自定义直链。
2. 锁屏不响：检查全屏通知与精确闹钟权限是否授予。
3. 校验不过：换一个 API 地址再测，确认网络能访问该地址。
4. 切换 API 后需重新测试，旧结果会作废。
5. 响铃只有震动：多为歌单 VIP/版权曲目或响铃时无网络，换非付费歌单或改用自定义直链。
